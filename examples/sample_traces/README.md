# Sample Traces

This directory contains example forensic traces for the Deterministic Forensic Observatory.

## Files

### deterministic_run.json

A complete single-run forensic trace (10,000 ticks) in Q31.32 fixed-point format.

**Schema:**
```json
{
  "ticks": [
    {
      "tick": 0,
      "mode": 0,
      "confidence": 100,
      "energy_norm": 42949672960000,
      "rollback_count": 0,
      "learning_delta": 0,
      "hashes": {
        "struct_hash": "...",
        "energy_hash": "...",
        "topo_hash": "...",
        "memory_hash": "..."
      }
    }
  ]
}
```

**Fields:**
- `tick` — Tick counter (usize)
- `mode` — Execution mode (0=normal, 1=learning, 2=rollback)
- `confidence` — Confidence metric [0, 100]
- `energy_norm` — Energy value in Q31.32 fixed-point
- `rollback_count` — Rollback attempts since tick 0
- `learning_delta` — Learning rate delta
- `hashes` — Four domain hashes (struct, energy, topology, memory)

**Usage:**
```bash
# Validate trace
cargo run --release -- validate deterministic_run.json

# Export forensic report
cargo run --release -- forensic-export deterministic_run.json

# Launch interactive GUI
cargo run --release -- observatory-gui deterministic_run.json
```

## Creating Your Own Traces

Traces can be generated by:
1. Running kernel telemetry capture (Phase 2V)
2. Exporting to Q31.32 format via `telemetry_reader::export()`
3. Placing in this directory for analysis

See [QUICKSTART.md](../../QUICKSTART.md) for examples.
